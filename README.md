# Deployer application (electron)
A Node.js web application based on Electron framework to deploy a project to a server.

### Prerequisites:

1. To use Electron, you need to install Node.js. We recommend that you use the latest LTS version available.

### How to install the project

1. Run "**npm install**" command in the project directory to install the dependencies.
2. Run "**npm start**" command to start the application.
